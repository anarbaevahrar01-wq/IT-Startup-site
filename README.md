# QR DINE — онлайн тапсырыс беру жүйесі

## Жоба туралы

**QR DINE** — кафе мен мейрамханаларда тапсырыс беруді жеңілдетуге арналған веб-қосымша.

Жобаның мақсаты — клиенттердің уақытын үнемдеу, тағам таңдауды ыңғайлы ету және тапсырыстарды электронды түрде қабылдау.

Клиент сайттағы мәзірден тағамдарды таңдап, себетке қосады және тапсырысын жібереді.

## Жұмыс істейтін сайт

**Сайт сілтемесі:** [ОСЫ ЖЕРГЕ RENDER СІЛТЕМЕСІН ҚОЙЫҢЫЗ]

## Қолданылған технологиялар

- **HTML** — веб-беттердің құрылымы.
- **CSS** — сайттың дизайны және мобильді құрылғыларға бейімделуі.
- **JavaScript** — мәзірді жүктеу, себет және тапсырыс беру.
- **Python + Flask** — серверлік логика және API.
- **SQLite** — тағамдар мен тапсырыстар деректер базасы.
- **Render** — жобаны интернетке орналастыру.
- **GitHub** — бастапқы кодты сақтау.

## Негізгі мүмкіндіктер

- Электронды мәзірді көру.
- Тағамдардың суреті мен бағасын көру.
- Тағамдарды себетке қосу.
- Тағам санын көбейту немесе азайту.

## Сайтты пайдалану

1. Жоғарыдағы Render сілтемесі арқылы сайтты ашыңыз.
2. «Мәзір» бөліміне өтіңіз.
3. Қажетті тағамдарды таңдаңыз.
4. «+ Себетке» батырмасын басыңыз.
5. Себеттегі тапсырысты тексеріңіз.
6. Атыңызды енгізіңіз.
7. «Тапсырыс беру» батырмасын басыңыз.

Тапсырыс Flask серверіне жіберіліп, SQLite деректер базасына сақталады.

## API

- `GET /api/health` — сервердің жұмысын тексеру.
- `GET /api/menu` — тағамдар тізімін алу.
- `POST /api/orders` — тапсырыс жіберу.
- `GET /api/orders` — сақталған тапсырыстарды көру.
